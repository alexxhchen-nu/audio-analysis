# 跨视频聚类结果（no-vocals / MERT）

这是基于项目中现有音频向量做的探索性聚类。可在 VS Code 中直接打开此文件夹；本说明是结果入口，主流程代码位于项目的 [`notebooks/master.ipynb`](../../../notebooks/master.ipynb) 的“Cross-video clustering”单元。

## 本次数据

- 表示：MERT-v1-95M 音频向量（768 维），只取 `no_vocals` 音轨。
- 仅使用完整的 5 秒窗口；不足 5 秒的补零尾窗被排除。
- 共 3 个视频样本：分别有 7、10、81 个窗口，总计 98 个。
- 另做每个视频均匀抽取 7 个窗口的平衡版本，共 21 个窗口，避免长视频仅因窗口数量多而支配聚类。

## 文件索引

- `all_windows_assignments.csv`：98 个窗口的 k=3 聚类标签和时间范围。
- `balanced_assignments.csv`：平衡抽样后 21 个窗口的 k=3 标签。
- `silhouette_sweeps.csv`：k=2 至 k=6 的轮廓系数。
- `k3_sample_composition.csv`：每个簇包含的各视频窗口数。
- `all_windows_k3_pca.png`：全部窗口的二维 PCA 可视化。PCA 只用于绘图；聚类在原始归一化 MERT 向量上完成。

## 结果解读

平衡数据上，k=3 的轮廓系数为 0.365，k=4 为 0.384；k=3 恰好按来源视频分组。这表明当前向量/数据集可能主要保留视频来源或录音差异，而不是共同的语义主题。窗口彼此有重叠，且样本只有 3 个，因此这只是探索结果，不是稳定的语义分类，也不能用于推断视频意图。

要研究跨视频的共同主题，需要加入更多独立来源的视频、减少重复/重叠窗口的影响，并结合 ASR 转写、标题或人工标注后再评估。
